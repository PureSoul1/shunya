🦊 Shunya AI Assistant - Quick Setup Guide
Welcome to Shunya! Your stealth AI assistant for meetings, interviews, and calls.
Follow these 3 simple steps to get started.

🗝️ Step 1: Activate Your License
To use Shunya, you need a valid license key.

Open the Shunya app and go to Settings (⚙️).
Find the "Shunya API / License" section.
Enter your license key (Format: SHUNYA-XXXX-XXXX-XXXX-XXXX).
Click Activate.
⏳ First time? Our server sleeps to save costs. The first activation might take 30-40 seconds. Please wait!

🤖 Step 2: Set Up Your AI Chat (BYOK)
Shunya uses BYOK (Bring Your Own Key). This means you use your own AI API key. No monthly subscription fees!

Go to Settings -> AI Providers.
Select an AI Provider from the list (e.g., Groq, OpenAI, Gemini, Claude).
Enter your API Key in the API_KEY field.
💡 Recommendation: Use Groq. It is super fast and has a free tier!
Get your free Groq key here: https://console.groq.com/keys

🎤 Step 3: Set Up Your Microphone (Voice-to-Text)
If you want to ask questions using your voice, you need to set up the Speech-to-Text (STT) provider.

Go to Settings -> Speech / STT.
Select a Speech provider (e.g., Groq Whisper, OpenAI Whisper).
Enter your API Key in the API_KEY field.
⚠️ Important: The Chat API key and Voice API key are set in different places. If you get an "Invalid API Key" error on voice, make sure you have entered the key in the Speech settings too!

💡 Pro Tip: If you are using Groq for Chat, you can use the same Groq API key for Voice as well. Just select "Groq Whisper" and paste the same key.

🚀 You're Ready!
You are all set! Use these shortcuts to use Shunya like a pro:

Open Dashboard: Ctrl + Shift + D
Toggle Overlay: Ctrl + \\
Take Screenshot: Ctrl + Shift + S
Start Voice Recording: Ctrl + Shift + A
System Audio Capture: Ctrl + Shift + M
