🦊 Shunya AI Assistant
Your Stealth AI Copilot for Meetings, Interviews, and Calls.
Shunya is a stealth AI assistant that stays invisible on your screen, listens to your meetings, and provides real-time AI answers without anyone knowing. Built for professionals who need an unfair advantage.

Shunya AI Assistant

✨ Key Features
🥷 Stealth Overlay: Invisible AI assistant that stays on top of your screen.
🎙️ System Audio Capture: Listen to Zoom/Meet calls and provide real-time answers.
💡 Auto-Suggestion Mode: Get smart AI suggestions on the fly.
📷 Screenshot Analysis: Attach screenshots and get instant AI insights.
🎤 Voice-to-Text: Ask questions using your microphone.
🔑 BYOK (Bring Your Own Key): Use your own AI API keys (OpenAI, Groq, Gemini, Claude). Zero API markup!
🗝️ Quick Setup
Download and install Shunya.
Enter your license key.
Add your AI API key (Get a free Groq key here).
Start using Shunya in your next meeting!
